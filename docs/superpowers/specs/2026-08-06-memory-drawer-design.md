# 回忆抽屉与语录圆点设计

## 目标

将首页内嵌的横向回忆时间轴迁移为由左上角“秦彻·你”打开的左侧抽屉。抽屉采用纵向、图片驱动的档案式时间轴；主页仍在后方隐约可见。语录切换圆点恢复为单行展示。

## 交互与布局

- 点击左上角“秦彻·你”打开左侧回忆抽屉；再次点击、点击遮罩、点击关闭按钮或按 `Esc` 均可关闭。
- 桌面端抽屉约占可视宽度的 42%，最大宽度受限；移动端占满可视宽度，保证文字可读与操作可触达。
- 打开时保留当前主页滚动位置，后方覆盖一层柔和暗色遮罩；关闭后回到原位置。
- 首页中现有的回忆时间轴区块移除，照片墙紧接首页内容。
- 抽屉内是正常纵向滚动的时间线：左侧连续时间线与节点，右侧为横向图片回忆条目。

## 回忆条目

- 每个条目使用照片作为完整背景，并以 `cover` 裁切为统一横向比例。
- 图片底部覆以低饱和暗红至透明的渐层；日期、标题和展开内容直接浮在图上。
- 点击条目仍会选中、展开内容，并保留新增记忆、删除按钮与删除确认弹窗。
- 按日期生成的照片回忆优先采用该日期下的照片；固定回忆和自定义记忆使用稳定的确定性规则从当前照片库选择回退图片，确保同一条记忆不会在每次打开时随机变换。
- 用户未上传图片或候选图片不可用时，使用现有照片库的安全回退，不新增远端依赖。

## 视觉

- 延续页面现有的黑色、暗红、酒红与暖金色体系，不引入蓝色表层。
- 深色主题为深棕黑基底、暗红遮罩和暖白文字；浅色主题使用偏浅的红棕遮罩和深酒红文字。
- 保持时间轴清晰，不使用厚重的纯黑内容框。

## 语录圆点

- 语录圆点固定单行，不再自动换行。
- 过多圆点时保留可点击性：容器可横向滚动，手机端可手势横向滑动。
- 现有自动轮播、点击切换、无障碍标签与自定义语录标识保持不变。

## 验收

- “秦彻·你”可可靠地开关回忆抽屉，且不影响其他导航入口。
- 回忆条目的打开、展开、新增与删除行为保持可用。
- 深浅主题下，文字均在图片上清晰可辨。
- 语录圆点在桌面和手机端均为单行，仍可切换全部语录。

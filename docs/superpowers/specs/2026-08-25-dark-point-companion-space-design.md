# 暗点陪伴空间设计

## 目标

将现在较薄的“暗点”弹窗升级为素材化的陪伴空间。首页的结构、语录、照片墙、播放器、聊天入口和回忆抽屉均保持原样；右上乌鸦菜单只保留“数据备份”和“内容管理”。原菜单中的其他功能继续使用原有数据和面板，但从暗点里的空间物件进入。

## 信息架构

- 导航栏“暗点”与首页状态卡仍打开 `roomPanel`。
- 乌鸦菜单只保留 `backup`、`manage` 两个既有面板入口。
- 暗点内的物件先选中，再在物件操作条中显示对应功能：
  - 窗边：经期记录、纪念日。
  - 书桌：待办清单、番茄钟。
  - 回忆柜：回忆时间轴、我的私藏。
  - 信箱：未来信件。
  - 游戏台：贪吃鸦。
- 唱片机作为氛围物件显示当前播放状态，不新增音乐数据或第二个播放器。

## 视觉与素材

- 深色主题使用现有的酒红、深棕黑、暖白和暗金变量；不新增蓝色表层。
- 浅色主题保留同一布局，但使用浅红棕面板与深酒红文字，功能热点、状态按钮和关闭按钮必须清晰可见。
- 将用户提供的、没有明显水印的素材复制到 `assets/dark-point/`：
  - `D:\small progect\png素材\image 11.png` -> `qinche-seated.png`：默认右侧主视觉。
  - `image 54.png`、`image 55.png` -> `silhouette-watch.png`、`silhouette-crow.png`：低透明度氛围剪影。
  - `image 61.png` -> `red-foliage.png`：红色植物边缘装饰。
  - `image 66.png` -> `qinche-signature.png`：右下角签名。
  - `image 69.png` -> `feather.png`：小型互动点缀。
- 人物主视觉只占场景右侧，功能热点不覆盖脸部或主体手部；植物和剪影只在边缘出现。

## 交互

- `roomPanel` 仍是覆盖层；桌面端最大宽度提升为宽场景，移动端占满或接近占满可视宽度。
- 物件使用原生 `button`，带可见焦点、`aria-pressed` 和清晰名称。选中后更新下方操作条标题与按钮。
- 点击操作条中的项目先关闭暗点，再复用现有入口：`openUtilPanel('period')`、`openUtilPanel('anniversary')`、`openUtilPanel('todo')`、`openUtilPanel('pomodoro')`、`memoryDrawerController.open()`、`openUtilPanel('privateVault')`、`openUtilPanel('letters')`、`openUtilPanel('snake')`。
- 现有 `ROOM_STATE_KEY`、状态单选、首页状态卡和所有 localStorage/IndexedDB 数据保持不变。

## 非目标

- 不重做首页，不移动照片墙、语录、播放器或聊天区。
- 不引入云端服务、账户系统、外部接口或收费依赖。
- 不改动未来信件、经期、待办、私藏、番茄钟、贪吃鸦的既有内部逻辑。

## 验收

- 乌鸦菜单只显示数据备份和内容管理。
- 暗点包含五个可到达的功能物件，覆盖原菜单中所有被迁移的入口。
- 每个物件的操作条可打开对应的既有功能，原数据仍可读写。
- 深色与浅色主题、桌面与手机宽度下文字、热点和关闭操作均清晰可用。
- 首页内容和回忆抽屉的触发方式不回退。
